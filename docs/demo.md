# Five-minute demo

1. Run `docker compose up`, open http://localhost:3000, then **Setup & services**. Explain that offline coaching is explicitly labelled and every service has a purpose/configuration indicator.
2. Open **Pitch room**, select **Strong pitch**, choose **Real VC** and **Take the floor**. Type an answer about the paid pilot. The four personas react through distinct lenses and disagree. Show interest, transcript, follow-up, optional timer and voice fallback.
3. Answer twice more, separating measured delivery costs from unknown churn. Finish the pitch. Show six scores, actual quoted gaps, the rewritten pitch's placeholders and five preparation questions. Use **Pitch again** to demonstrate a linked retry and later scorecard overlay.
4. Open **Challenge the idea's assumptions**. Show labelled defaults, missing researched top-down TAM, bottom-up market and Revenue. Explain that a good-looking projection is conditional on inputs.
5. Open **What if?**, move monthly price or churn, and point out **0 model calls**. Save a new version and compare it with its parent. Adjust wedge weights and inspect risk thresholds.
6. Open **Share**, include only Market, create a short-lived link, open it in another browser, then revoke it. Show JSON/CSV export and PDF. A public report cannot edit or expose unselected assumptions.
7. Open **Your progress**. Seed labelled weak/developing/strong examples if desired. They are synthetic and excluded from real-user benchmarks. Cohorts expose aggregate metrics only after consent and minimum sample thresholds.

For a live demonstration, first provide Firebase/ADC and Gemini credentials, run the provider probe and bake-off, and use the research consent fields. Show actual source links and provider metadata. Optional Google speech sends audio/text only through explicit controls. Never present the offline heuristics as live reasoning or the illustrative market inputs as researched facts.
